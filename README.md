# Classroom · 전주 용소중학교 2026년 2학년 1반

웹앱 링크 : muz.so/용소21생활기록

## How to Use

Student : 이름 선택 → 학번(2101~2128) 입력 → 기록 조회 가능

Admin :  관리자 비밀번호로 로그인 → 학생 선택 → 기록 추가/최근 기록 취소 가능. 비밀번호는 Cloudflare Secret 에 보관중.


## UI and Server

- html: 화면 구성
- css: 디자인 설계
- js: 명단, 조회, 그래프, 버튼 동작 로직 구현
- js: API 서버 주소 연결
- mjs: 서버 인증, 조회/추가/취소 API 연결
- Cloudflare D1 Server 테이블·인덱스·집계 트리거


## When This Webapp Use Server API ??

- 첫 화면·명단·검색: API/D1 요청 0회
- 관리자 로그인: API 1회, D1 접근 없음
- 학생 학번 확인+조회: API 1회, SELECT 3개를 D1 batch 1회로 처리
- 조회 결과: 메모리에 60초 캐시. 같은 학생의 동시 조회는 하나로 병합
- 자동 주기 조회 없음. 캐시 만료만으로 자동 요청하지 않음
- 추가/취소: 변경과 최신 결과를 하나의 batch로 반환하여 별도 조회 없음
- 누적/월별 합계를 미리 집계. 최근 내역은 최대 50개, 누적 합계는 전체 반영
- UUID로 중복 추가 방지, 자동 재시도 없음
- Cloudflare 위치별 IP당 약 120회/분, 로그인 약 30회/분 제한. 학교 Wi-Fi에서는 공인 IP를 공유하므로 합산됨


## 인증·저장 특성

관리자 세션은 1시간, 학생의 읽기 전용 세션은 15분이며 HMAC 서명됨.
